## Hades Build Tracker

This app is to help me keep track of my most powerful builds in Hades 1. Will improve it for Hades 2

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
