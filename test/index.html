Disclaimer

In order for the tool to work at all you need to have JavaScript enabled. Also, please keep in mind that the tool is currently in version 0.1.1, so just expect to encounter some bugs. If so, please report them to me, so I can do my best to fix them.

Furthermore, this was my first ever big web-project. I made this just for fun. Therefore the tool has some important limitations:

  • The tool might not work properly on every browser or operating system.
  • If you can try using the latest version of Chrome on a windows machine.
  • The tool does not work properly at all on any kind of touch devices.
  • Please use a desktop or laptop computer instead.
  • The tool does not work properly on very small screens.
  • Try to zoom out on the tool Ctrl + Scroll.

All currently known issues are listed under Patch Notes. Thanks for understanding.
